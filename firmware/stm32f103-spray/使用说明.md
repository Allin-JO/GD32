# 消毒喷雾机械臂（融合版）使用说明

> 适用工程：`总线舵机` 文件夹下的 STM32 工程（Keil MDK，STM32F103C8T6）
> 本工程将 **喷雾模块 + 水泵 + 秤（HX711）+ 机械臂（总线舵机）** 融合到同一块 STM32 上。

---

## 1. 功能简介

| 功能 | 说明 |
|---|---|
| 喷雾 | PA1 输出高电平开启、低电平关闭 |
| 水泵 | PA4（MOS管驱动）高电平工作、低电平关闭，工作状态下周期性抽水 |
| 称重上传 | HX711 读取剩余消毒液重量，每 3 秒向上位机发送一次 `{"weight":xxx}` |
| 机械臂控制 | 上位机发送 `{"control":1}` 启动工作模式、`{"control":0}` 关闭 |

**机械臂位置（定点位模式）：**

| 状态 | 舵机1 | 舵机2 | 喷雾 | 水泵 |
|---|---|---|---|---|
| 非工作状态 | 510 | 待定（暂 0） | 关 | 关 |
| 工作状态 | 430 | 待定（暂 0） | 开 | 周期性抽水 |

上电后：舵机上电回**非工作位置**（舵机1=510），喷雾/水泵关闭，等待指令。
收到 `{"control":1}`：舵机转到工作位置（舵机1=430），喷雾开启，**水泵每隔设定秒数抽一次水**。
收到 `{"control":0}`：喷雾/水泵关闭，舵机回到非工作位置（510）。

## 2. 引脚分配

| STM32 引脚 | 功能 | 连接对象 |
|---|---|---|
| PA9 | USART1_TX 舵机指令 | BusLinker RX |
| PA10 | USART1_RX 舵机应答 | BusLinker TX |
| PA2 | USART2_TX 发送重量 | USB转TTL → 上位机 RX |
| PA3 | USART2_RX 接收控制指令 | USB转TTL ← 上位机 TX |
| PA1 | 喷雾控制 | 喷雾模块控制端（高电平开） |
| PA4 | 水泵控制（MOS管） | 水泵驱动板信号端（高电平工作） |
| PA0 | HX711 SCK | HX711 模块 |
| PB1 | HX711 DOUT | HX711 模块（**原 PA1 已被喷雾占用，改到 PB1**） |
| PB8 / PB9 | OLED（软件 I2C） | OLED 显示屏 |

> ⚠️ PA1 原本是 LED1，本工程已改为喷雾控制，不要再调用 `LED_Init()`。
> HX711 的 DOUT 已从原秤工程的 PA1 改到 **PB1**，接线时注意。
> 水泵引脚在 `Pump.h` 中定义为 PA4，可按实际接线修改。

## 3. 上位机通信协议

**串口参数：** 9600，8 数据位，1 停止位，无校验（USB转TTL 接 PA2/PA3）。

### 3.1 单片机 → 上位机（重量上传）

每 3 秒发送一次（间隔可用 `WEIGHT_READ_MS` 调整）：

```text
{"weight":123}\r\n
```

- `weight` 单位：克（g），表示**剩余消毒液**的重量（已扣除空壶皮重）
- 上位机只需按行读取并解析 JSON 即可

### 3.2 上位机 → 单片机（指令）

```text
{"control":1}   // 启动工作模式
{"control":0}   // 关闭
{"tare":1}      // 去皮：空壶放在秤上时发送，去皮值自动存入 Flash
```

- 必须使用 **ASCII 半角** 引号和冒号（标准 JSON 格式）
- 一条指令以 `}` 结束即可解析，`\r\n` 可有可无
- **`{"tare":1}` 请在机械臂关闭、秤上没有额外物品时发送**（空壶状态）

### 3.3 串口调试示例（发送端）

```text
{"tare":1}        // 首次使用：空壶放好后去皮并保存
{"control":1}     // 开始喷洒（水泵周期性抽水）
{"control":0}     // 停止
```

## 4. 水泵抽水设置

水泵**仅在工作状态下**运行，间隔和每次抽水时长在 `main.c` 顶部配置：

```c
#define PUMP_INTERVAL_MS  10000 /* 每隔多少毫秒抽一次水 (10秒=10000), 按实际情况调整 */
#define PUMP_ON_MS        2000  /* 每次抽水持续毫秒数 (2秒=2000), 按实际情况调整 */
```

示例（默认值）：

- 间隔 10 秒（`PUMP_INTERVAL_MS = 10000`），每次抽 2 秒（`PUMP_ON_MS = 2000`）
- 进入工作状态后**立即抽一次**，之后每 10 秒抽一次

按实际水泵流量/喷头消耗调整这两个值即可。

## 5. 去皮与校准（重要）

### 5.1 去皮（零点设置）

储液壶**一直放在秤上**，所以开机**不会自动去皮**（否则会把壶里现有消毒液一起清零）。

正确流程：

1. 把储液壶清空（**空壶**）放在秤上
2. 上位机发送 `{"tare":1}`
3. 单片机取 20 次平均作为零点，并**写入 Flash**（掉电不丢失）
4. 以后每次开机自动读取 Flash 里的去皮值，上报的 `weight` 就是剩余消毒液重量

> 若 Flash 中没有去皮值（首次使用/换过单片机），则从 0 开始，上报的是秤上绝对重量（含壶），此时请按上述步骤去皮。

### 5.2 HX711 校准（SCALE）

`main.c` 中：

```c
#define SCALE   430.0f   // 原始值/g（已调试好，勿改）
```

校准方法（如需重新校准）：

1. 空载去皮
2. 放一个已知重量砝码（如 100g），记录原始值变化
3. `SCALE = |加载后原始值 - 空载原始值| / 砝码重量(g)`
4. 修改 `SCALE` 后重新编译烧录

## 6. 舵机位置配置

位置定义在 `main.c` 顶部，直接改宏后重新编译即可：

```c
#define SERVO1_IDLE_POS   510   /* 舵机1 非工作状态位置 */
#define SERVO1_WORK_POS   430   /* 舵机1 工作状态位置 */
#define SERVO2_IDLE_POS   0     /* 舵机2 非工作状态位置 (待定) */
#define SERVO2_WORK_POS   0     /* 舵机2 工作状态位置 (待定) */
#define SERVO_MOVE_MS     800   /* 舵机运动到位时间(毫秒) */
```

- 位置范围 0~1000，对应物理角度约 0~240°
- 舵机2 的两个位置目前**待定**（暂为 0），确定后改对应宏即可

## 7. 使用步骤

1. **接线**：按第 2 节引脚表连接舵机、喷雾、水泵、HX711、OLED、USB转TTL
2. **首次去皮**：空壶放在秤上，上位机发送 `{"tare":1}`
3. **编译**：用 Keil 打开 `Project.uvprojx`，编译
4. **烧录**：用 ST-Link / 串口 ISP 烧录到 STM32F103C8T6
5. **上位机**：打开串口助手（9600），发送 `{"control":1}` 启动、`{"control":0}` 关闭
6. 观察 OLED 显示重量与 Mode（WORK/OFF），上位机每 3 秒收到一条 `{"weight":xxx}`

## 10. 注意事项

1. **PA1 喷雾与 LED1 冲突**：原 LED 模块把 PA1/PA2 当 LED，本工程 PA1 已用于喷雾。
2. **HX711 DOUT 在 PB1**：与原秤工程（PA1）不同，接错会读不到数据。
3. **JSON 必须用半角符号**：`{"control":1}`，全角引号/冒号不会被解析。
4. **开机不自动去皮**：去皮通过 `{"tare":1}` 指令在空壶状态下手动完成，结果存 Flash。
5. **读秤会阻塞约 0.5 秒**：每 3 秒一次，机械臂动作会每 3 秒短暂停顿，属正常现象。
6. **水泵/舵机供电**：舵机需外部电源（6~8.4V）；水泵由 MOS 管驱动，注意单独供电与共地。
7. 原 `秤` 文件夹是旧版独立工程，保留作备份，可自行删除。
