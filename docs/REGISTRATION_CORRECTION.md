# 报名信息更正说明

## 更正内容

| 项目 | 原报名信息 | 实际硬件 |
|---|---|---|
| 运动主控 | GD32H759 | **GD32F303RCT6** |
| 喷洒控制 | 未单独列出/以报名表为准 | **STM32F103C8T6** |
| 实时操作系统 | 以报名表为准 | **RT-Thread 4.1.1** |

## 说明

本项目实际样机采用 **GD32F303RCT6 运动主控 + STM32F103C8T6 喷洒控制** 的双 MCU 架构。报名信息中的 **GD32H759** 为误填/旧信息，不是本项目样机的实际主控型号。

当前 GitHub 仓库中的代码、Keil 工程、硬件引脚说明、系统架构图和投稿文档均以实际硬件为准：

- 运动主控工程：`firmware/gd32f303-main/`
- 喷洒控制工程：`firmware/stm32f103-spray/`
- GD32 芯片：`GD32F303RCT6`
- STM32 芯片：`STM32F103C8T6`
- RT-Thread：`4.1.1`

## 报名系统建议填写文本

**项目硬件说明：**

> 本项目采用 GD32F303RCT6 作为运动主控，负责四路编码电机闭环控制与差速运动；采用 STM32F103C8T6 作为喷洒控制板，负责总线舵机、雾化模块、补液泵和 HX711 称重。两块下位机均运行 RT-Thread。报名信息中的 GD32H759 为误填，实际样机不使用该型号。
